## Overview

This project is a simple portable MP3 player using an ESP32 microcontroller. Built as a hands-on introduction to circuit design, schematic capture, and PCB layout.

## Hardware

| Component | Part |
|---|---|
| Schematic & PCB layout | KiCad |
| PCB manufacture | PCBWay |
| Microcontroller | ESP32-DevKitC |
| Audio decoder | DFPlayer Mini MP3 module |
| Storage | microSD card |
| Display | Adafruit 0.96" SPI OLED |
| Battery | 3.7 V 1100 mAh LiPo |
| Charging | TP4056 |
| Regulator | AP2112K-3.3 |
| Audio out | Kycon STX-3000 3.5mm right-angle stereo jack |
| Controls | 5x tactile push buttons |
| Programming | Built into the DevKit (USB) |
| Passives | 1kΩ resistor, 10 µF and 0.1 µF decoupling caps, 100 µF bulk cap |
| Misc | SPDT slide switch, perfboard, headers, enclosure |
